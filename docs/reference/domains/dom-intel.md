# DOM Intel

域名：`dom-intel`

DOM 情报收集域，支持页面结构分析、元素指纹、动态行为追踪。

## Profile

- workflow
- full

## 典型场景

- 页面结构分析
- 元素指纹提取
- 动态行为追踪

## 常见组合

- dom-intel + browser
- dom-intel + hooks

## 代表工具

- `dom_scan` — 待补充中文：Scan a page: extract simplified HTML with visibility analysis, overlay detection, and list truncation.
- `dom_find_lists` — 待补充中文：Find main list containers in the current page (feed, search results, tables).
- `dom_diff` — 待补充中文：Compare two HTML snapshots and return the changes.
- `dom_optimize` — 待补充中文：Optimize HTML for token efficiency: strip styles, truncate long attributes, compress data-* attributes.
- `dom_extract_text` — 待补充中文：Extract clean text from HTML: collapse whitespace, describe form fields.
